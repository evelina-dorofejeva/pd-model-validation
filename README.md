# PD Model Validation

This repository demonstrates a basic validation workflow for Probability of Default (PD) model outputs.

## Contents
- Python notebooks for data checks, PD validation and visualization
- SQL scripts for data quality and join checks
- Validation report (PDF)

## Scope
The analysis focuses on:
- data quality and missing values
- PD pool logic and correctness
- basic risk differentiation and stability over time

This is a learning project based on a take-home task.
